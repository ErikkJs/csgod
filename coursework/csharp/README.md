# C#

A single C# lab demonstrating polymorphism via an `IShape` interface implemented by Rectangle, Triangle, and Circle classes with area computation. **Languages:** C#, Make.

| Folder | What it is |
|--------|------------|
| `lab14-shape-polymorphism/` | Console app: `IShape` interface with Rectangle/Triangle/Circle implementations (each computing `Area` and a `Display()`, Circle exposing a read/write `Radius`), plus a Makefile that builds it with the Mono C# compiler (`mcs`). |
