# Software Development (CMPS 3350)

C++ software-construction labs, several using X11/OpenGL as a vehicle. Split out of the old `graphics/` folder, where these were mixed in with the separate CMPS 3480 graphics course. **Languages:** C++, C, PHP.

| Folder | What it is |
|--------|------------|
| `lab01-animation-loop` | OpenGL + X11 animation-loop starter with particles, gravity, and collision detection. |
| `lab02-asteroids` | Asteroids game starter in X11/OpenGL — vectors, bullets, asteroid splitting — used as a project base. |
| `lab04-http-client-cpp` | Convert a raw-socket HTTP GET client from C to C++ and fix all warnings, plus a small PHP GET-param demo and a data-flow-diagram GIF. |
| `lab06-debugging-word-count` | Debugging exercise: repair a program that counts dictionary words whose 4th letter is `a` (reads `/usr/share/dict/cracklib-small`). |
| `lab12-note-frequency` | Musical-note frequency calculator: converts a note name + octave delta to Hz using equal temperament. |
| `lab13-letter-frequency` | Letter-frequency counter that tallies a string and prints its letters sorted most-frequent first (with a `cmpslib.h` helper). |
