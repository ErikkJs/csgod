# Programming Languages (CMPS 3500)

Course labs exploring language paradigms and features across C++, Java, Ada, and Perl. **Languages:** C++, Java, Ada, Perl, C.

| Folder | What it is |
|--------|------------|
| `lab1` | C++ templated generic `List<T>` class with a custom `RangeError` exception, bubble sort, swap/max, and copy-semantics tests |
| `lab4` | Intro-to-Java coin-toss simulation plus a class that reads an exam-scores file and prints per-exam means |
| `Lab8` | Perl text-processing scripts: one tabulates sales figures, one tokenizes a C source file (counting words, ints, floats, braces) over a sample raw-socket HTTP GET client |
| `lab9` | Ada program that reads two 3x5 integer matrices from a file, multiplies them element-wise, and writes the result to an output file |
| `finale` | Perl stock-portfolio valuator: joins personal holdings with price/name data (CSV or tab), computes values, and interactively "liquidates" a symbol |
