# Programming Languages (CMPS 3500)

Course labs exploring language paradigms and features across C++, Lisp, Java, Ada, and Perl. **Languages:** C++, Common Lisp, Java, Ada, Perl, C.

| Folder | What it is |
|--------|------------|
| `lab01-cpp-generic-list` | C++ templated generic `List<T>` class with a custom `RangeError` exception, bubble sort, swap/max, and copy-semantics tests |
| `lab02-lisp-basics` | Common Lisp: iterative/recursive dot printing, count a's, Fibonacci, greater-of, summation |
| `lab03-lisp-lists` | Common Lisp: list remove, recursive remove, flatten, palindrome check, and prefix-to-infix conversion |
| `lab04-java-intro` | Intro-to-Java coin-toss simulation plus a class that reads an exam-scores file and prints per-exam means |
| `lab08-perl-text-processing` | Perl text-processing scripts: one tabulates sales figures, one tokenizes a C source file (counting words, ints, floats, braces) over a sample raw-socket HTTP GET client |
| `lab09-ada-matrix-multiply` | Ada program that reads two 3x5 integer matrices from a file, multiplies them element-wise, and writes the result to an output file |
| `final-perl-portfolio` | Perl stock-portfolio valuator: joins personal holdings with price/name data (CSV or tab), computes values, and interactively "liquidates" a symbol |
