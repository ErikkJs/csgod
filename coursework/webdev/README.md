# Web Development

Two iterations of a PHP/MySQL Bootstrap e-commerce store selling aftermarket car parts (cold-air intakes, turbo kits, exhausts, intercoolers). **Languages:** PHP, SQL, HTML, CSS, JavaScript.

| Folder | What it is |
|--------|------------|
| `project2` | Storefront on a `Products` table: sortable catalog (rating/price), session shopping cart with qty update and empty, login/logout, and an admin panel that inserts/updates/deletes products with prev/next row paging. |
| `project3` | Extends project2 with a full `Users` table: registration, DB-backed login, and an account page to change username/email/password, alongside the same catalog, cart, and admin. |
