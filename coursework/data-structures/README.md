# Data Structures (CMP222 / CMPS2020)

C/C++ coursework covering linked lists, stacks, heaps, and sorting, alongside the OOP fundamentals, lecture notes, labs, homework, and midterm that lead up to them. **Languages:** C++, C.

| Folder | What it is |
|--------|------------|
| `binarynotes.cpp` | Scratch notes and partial pseudocode for a recursive `binary_search` (not compilable). |
| `oop-foundations` | C++/OOP foundations: a `Car` class + dealer demo, class exercises (TennisPlayer, DateTime with operator overloading, exception handling), a `GameLevel` deep-copy/file-load assignment, cmpslib logger-instrumented labs, a C file-decryption lab, midterm class problems, and lecture notes on enums and inheritance/polymorphism. |
| `homework` | Data-structures homework: singly linked list, doubly-linked circular list of processes, an array-backed stack class, and quicksort/insertion-sort with median-of-three over a word list. |
| `labs` | Lab series (lab1-14 + ilabs): function/pointer overloading, gdb crash debugging, an array-index linked list in C, bracket-matching stack, Fibonacci recursion timing, function-pointer sorting, and a heap/heapsort, plus word-list and test-case fixture files. |

> `oop-foundations/` is the earlier OOP-fundamentals phase and has its own `homework/` and `labs/`; the top-level `homework/` and `labs/` are the later data-structures phase. Kept separate on purpose — the same-named files differ between the two, so they are two distinct versions, not duplicates.
