# Computer Graphics (CMPS 3480) & CMPS 3350 Labs

X11/OpenGL graphics and ray-tracing coursework (CMPS 3480) alongside assorted CMPS 3350 systems/debugging labs. **Languages:** C++, C, PHP, HTML.

| Folder | What it is |
|--------|------------|
| `1` | CMPS 3350 Lab 1: OpenGL + X11 animation-loop starter with particles, gravity, and collision detection (in `lab1/`). |
| `2` | Asteroids game starter in X11/OpenGL — vectors, bullets, asteroid splitting — used as a 3350 project base. |
| `3480` | CMPS 3480 Computer Graphics course, labs 1–c: X11 draw primitives, area fills, orthographic/perspective ray tracers, OpenGL rotation, Perlin noise, and GIF/image processing, plus the "Masterball" reflective-sphere ray-tracing final project. |
| `4` | CMPS 3350 lab: convert a raw-socket HTTP GET client from C to C++ and fix all warnings, plus a small PHP GET-param demo and a data-flow-diagram GIF. |
| `6` | Debugging lab: repair bugs in a program that counts dictionary words whose 4th letter is 'a' (reads `/usr/share/dict/cracklib-small`). |
| `c` | Musical-note frequency calculator: converts a note name + octave delta to Hz using equal temperament. |
| `d` | Lab 13 challenge: letter-frequency counter that tallies a string and prints its letters sorted most-frequent first (with `cmpslib.h` helper). |
