# csgod

A personal archive of undergrad CS coursework and self-study — spanning operating systems, graphics, AI/ML, networks, security, and web, in whatever language the work called for. Every folder has a README, so you can tell what's inside without opening a single source file.

## Highlights

- **[`ai-learnings/`](ai-learnings/)** — 24 neural-network architectures built from scratch in Python: perceptron → CNNs → RNN / LSTM / GRU → attention & Transformer → autoencoders / VAE / GAN → deep RL (Q-learning, DQN). Each file is a self-contained, commented implementation.
- **[`leetcode/`](leetcode/)** — 108 problems solved in C++, each with its own solution and test file.
- **[`projects/rambo/`](projects/rambo/)** — a 2D SDL / OpenGL arcade game built as a team, with sprite sheets, sound, and a leaderboard.
